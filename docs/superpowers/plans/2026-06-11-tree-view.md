# Tree View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `tree[@id]: [...]` directive that renders a binary tree from a LeetCode-style level-order array (accepting JSON `null` and Python `None`) in the existing graph panel, reusing the whole graph pipeline.

**Architecture:** `tree:` is a new front-end for *defining* structure only. It decodes the binary-tree array into a children adjacency list and emits the existing `{ kind: "graph", mode: "tree", adjacency }` event, so `frameAt`, the step timeline, `@id` multi-graph, and `graph_node`/`graph_edge` decorations all apply unchanged. Rendering adds a rooted breadthfirst layout + no arrowheads for `mode === "tree"`.

**Tech Stack:** TypeScript, Cytoscape, Vitest (node env — parser only). Commands run from `apps/web/`.

**Spec:** `docs/superpowers/specs/2026-06-11-tree-view-design.md`

**Testing note (matches the graph feature):** the repo's Vitest env is `node` with no jsdom/RTL, so automated tests target the pure parser only. Tree directives are tested through the public `parseGraphProgram` + `frameAt` (internal helpers like `decodeBinaryTree` are not exported, mirroring the existing style). The Cytoscape rendering change is verified by `pnpm typecheck`, `pnpm lint`, and a scripted manual run.

Lint note: there is one PRE-EXISTING `react-hooks/refs` error in `PadEditorInner.tsx` unrelated to this work — leave it; just don't add new errors.

```ts
// Decode a LeetCode level-order binary-tree array into a children adjacency
// list keyed by compact level-order index (root = 0). `None` must already be
// normalised to null by the caller.
function decodeBinaryTree(vals: (number | null)[]): number[][] {
  if (vals.length === 0 || vals[0] === null) return [];
  const children: number[][] = [[]];
  const queue: number[] = [0];
  let i = 1;
  let next = 1;
  while (queue.length > 0 && i < vals.length) {
    const parent = queue.shift()!;
    for (let slot = 0; slot < 2 && i < vals.length; slot++) {
      const v = vals[i];
      i++;
      if (v !== null) {
        const idx = next;
        next++;
        children[idx] = [];
        children[parent]!.push(idx);
        queue.push(idx);
      }
    }
  }
  return children;
}

function parseTreeLine(
  id: string,
  body: string,
  structures: Map<string, number[][]>,
  warnings: string[]
): GraphEvent | null {
  // Accept Python None as well as JSON null; whitespace inside the array is
  // tolerated by JSON.parse.
  const payload = body.trim().replace(/\bNone\b/g, "null");
  let json: unknown;
  try {
    json = JSON.parse(payload);
  } catch {
    return null;
  }
  if (!Array.isArray(json)) return null;

  const vals: (number | null)[] = [];
  for (const v of json) {
    if (v === null) {
      vals.push(null);
    } else if (typeof v === "number" && Number.isFinite(v)) {
      vals.push(v);
    } else {
      return null; // strings, booleans, nested arrays, etc.
    }
  }

  const adjacency = decodeBinaryTree(vals);
  const n = adjacency.length;
  if (n > MAX_NODES) {
    warnings.push(`tree @${id} has ${n} nodes (max ${MAX_NODES}); ignored`);
    return null;
  }
  if (!structures.has(id) && structures.size >= MAX_GRAPHS) {
    warnings.push(`more than ${MAX_GRAPHS} graphs; @${id} ignored`);
    return null;
  }

  structures.set(id, adjacency);
  return { kind: "graph", id, mode: "tree", adjacency };
}
```
